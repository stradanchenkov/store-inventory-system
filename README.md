# store-inventory-system
Экзаменационный билет №20
Создание репозитория:
 
Проект: “Информационная система для отдела компьютерной техники”
Сведения о фирме:
•	Название: “TechnoSoft”
•	Сфера деятельности: разработка ПО для розничной торговли
•	Цель проекта: автоматизация учёта товаров и продаж в отделе компьютерной техники
•	Организационная структура: линейно-функциональная (руководитель проекта → аналитик → программисты → тестировщики)
Инициация проекта:
1.	Идея проекта: веб-приложение для управления товарами, продажами и складом.
2.	Название: “StoreInventory Pro”.
3.	Цель: повысить эффективность работы отдела на 40% за счёт автоматизации.
4.	Задачи:
o	Разработать базу данных (товары, сотрудники, продажи).
o	Реализовать интерфейс для учёта и отчётности.
o	Интегрировать систему с онлайн-кассой.
5.	Потребители: магазины компьютерной техники, отделы продаж.
6.	Потребности: скорость обработки запросов, точность данных, сокращение ручного труда.
7.	Обоснование: система снизит ошибки учёта, ускорит формирование отчётов, повысит удовлетворённость клиентов.
8.	Ожидаемые результаты:
o	Сокращение времени на оформление продажи на 30%.
o	Уменьшение потерь от пересортицы.
o	Автоматическое формирование отчётов для руководства.
9.	Сроки: 6 месяцев (анализ — 1 мес., разработка — 3 мес., тестирование — 1 мес., внедрение — 1 мес.).
